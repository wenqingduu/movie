## 补充诊断：筛选后的人物区域DINO 0.7863

本次保留的补充结果为 **0.7863：可见单脸门控＋三项人工定位纠错后的人物区域DINO**，是同一批生成视频的事后诊断，不是新生成实验，也不替代上表官方原始 **0.7155**。

**计算对象是生成视频中，同一集、同一调度角色在不同镜头里的原始官方人物区域裁剪。** 人脸检测仅用于筛选这些区域，DINO输入仍是原人物区域，可能包含头发、衣服和背景；不是重新裁出的人脸小框，不与人物参考素材比较，也不是3D注入前后对照。

| 项目 | 本次诊断口径 |
|---|---|
| 起点 | 全140集／2491镜头的4991个计划角色—镜头实例，沿用官方已选出的canonical人物区域 |
| 自动筛选 | 原判断为present，原区域恰有一张合格可见人脸；排除同镜头多个角色争用同一人脸轨迹等歧义 |
| 人工纠错 | 抽查80项，排除3项已确认裁到其他角色的区域；没有因画风、衣服、姿态、身份漂移或DINO低分直接删样本 |
| 保留区域 | **1697／4991（34.00%）**；其中**1380个角色—镜头实例**满足每角色至少两个有效镜头的跨镜头评分条件 |
| 聚合与结果 | 每个集内角色重建DINO质心，计算各人物区域与质心的余弦；集内按出现实例平均，再对**131个有效集**等权平均，得到**0.7863**；另9集无分数，不填0 |

这表示**筛选集合内的人物区域跨镜头聚集程度**，不是78.63%的身份正确率。覆盖集合与质心均发生变化，不能把相对0.7155的涨幅解释为生成质量或3D插件增益，也不能直接与论文排名。未运行VLM／保真度门控。

身份归属尚未全量核验。后续发现原复查保留的R051（run98／i10_j29，Toby 9:1）实际误配Felix，**该项仍包含在0.7863中，尚未据此重算**；不能称为“完全纠错后的分数”。完整规则、已知问题及来源见[诊断指标说明](docs/entitybench_qwen140_metric_interpretation_20261021.md#补充诊断可见单脸门控与定位纠错后的人物区域dino-07863)和[原始诊断报告](outputs/entitybench_qwen21_i2v_a14b_4step_continuation_full140/evaluation/character_region_visible_face_gate_20261025/remaining_low_score_review/recomputed/report.json)。

角色出现率仅保留官方全量 **0.9212**，不采用人脸门控子集出现率。人物区域DINO诊断 **0.7863** 的筛选集合不用于重新定义角色出现率的分母。

## 指标讨论：接手时保留的结论

完整定义、全量拆分、五组抽查证据、论文依据与不确定性见[当前实验指标解释](docs/entitybench_qwen140_metric_interpretation_20261021.md)。以下结论不修改上面的正式分数。

- **评测执行正确与指标局限可以同时成立。** 本次按冻结官方开源非VLM算法执行并通过独立核验，目前未发现执行／数值错误。出现率是检测与CLIP匹配通过率，不直接等同人工可见率或身份正确率；不能因个别人工可见样本未通过就否定官方结果或单独调低阈值。
- **角色失分更多集中在接续。** 实例统计的硬切通过率96.95%、接续88.87%；接续中上一镜头已调度角色92.41%、未调度角色86.45%。375次未通过中307次在接续，含222次上一镜头未调度角色和85次已调度角色。这是实例比率，不是正式的集等权0.9212；“新进入”按相邻调度名单定义，不证明实际尾帧中的可见性。接续阶段缺少独立人物参考和布局视觉条件是待验证的解释，未证明其失分贡献，也未证明四步蒸馏或3D注入的因果作用。
- **场景分数不能解释为对应比例的镜头没有背景。** 921条场景未通过记录均为weak，有候选区域但CLIP低于0.20。五组帧／裁剪抽查可见停机坪存在却未过线、卧室定位为照片、角色调度包含车轮特写中不可见的人等情况；没有全量人工误判率，不能把低分全部归于评测。未跑VLM不是presence偏低的直接原因。
- **硬切／接续安排继承benchmark，EntityMem也使用上一镜头末帧。** 本次1136个硬切按镜头要求生成新首帧，1355个接续用自身前视频实际尾帧。边界headline比较接续的末／首各一帧，不评硬切或几秒后的漂移。0.9822的绝对高分合理，但它相对EntityMem 0.7380的差距尚未解释清楚；已知门控／聚合差异不足以量化全部差距，缺少作者原始帧和对应执行配置，不能声称同等幅度的质量优势。
- **DINO结果分别解释。** 官方0.7155是原人物区域指标，补充0.7863是原人物区域经可见单脸门控及三项定位纠错后的子集诊断，独立0.8237是脸部裁剪质心指标；三者有效集合不同，均不是对参考身份的准确率。当前交接记录0.7863，不以继续剔除生成画风／身份失败样本后的假设分数替代；VLM仍暂不处理，正式数值不改。

## 接续条件与论文EntityMem的区别

**已核实的实现差异：本次接续给Wan的是“自身前段末帧＋本镜头文字”；论文EntityMem还直接给视频模型提供本镜头的人物参考和布局／关键帧记忆条件，可包含新进入角色的参考。** 人物素材即使已在本地准备，当前Wan接续调用也没有单独接收它们。本次Qwen人物参考条件及单人3D注入用于硬切首帧阶段，接续不再次运行该阶段。

| 视频生成阶段的接续输入 | 本次Qwen＋3D＋Wan四步 | 论文EntityMem |
|---|---|---|
| 上一镜头末帧 | 作为I2V输入 | 作为独立首帧输入，与记忆库分开 |
| 当前镜头文字 | 有 | 有，并可检索补充实体描述 |
| 本镜头各角色的独立视觉参考，含新进入角色 | 不额外提供给Wan | 有，作为记忆条件提供给视频模型 |
| 本镜头布局／关键帧参考 | 不额外提供给Wan | 有，角色进出时可规划多个关键帧 |

论文依据是[第4节Stage 3及附录C.1–C.2](https://arxiv.org/html/2605.15199v1#A3.SS1)；本地依据是[实际视频生成调用](pretest/run_lightx2v_a14b_4step_qwen140.py)中的`pipeline.generate(seed=..., prompt=shot["prompt"], image_path=...)`，接续的`image_path`来自自身前段解码尾帧，没有额外人物参考或关键帧图参数。

例如上一尾帧只有A、本镜头要求B入画：本次Wan依靠文字生成B；EntityMem还可提供B的外观和入画后的布局。这使“接续阶段缺少新角色直接视觉参考”成为优先排查方向。**目前没有补充这些条件的对照实验，不能认定它已解释全部出现率差距。** 尾帧接续本身是双方共同设置，不能单独用来解释本次比论文角色出现率低或边界分数高；末帧作为输入也不保证输出首帧逐像素一致。
